<div class="hero">$DA+DB+DC$ 最小 → 把 $\triangle CDA$ 繞 $C$ 轉 $60^\circ$<br>三段變成<b>一條折線</b> $A'D'+D'D+DB$，拉直就是 $A'B$</div>
<figure class="bkfig"><pre class="geo">A = (100.7, 22)
B = (258, 112.8)
m = mid(A, B)
kM = circle(m, A)
C = on(kM, 100.7, 112.8)
A' = rotate(A, C, 60)
kc = circle3(A, A', C)
A'B = line(A', B)
D = meet(kc, A'B, 123.1, 86.9)
D' = rotate(D, C, 60)
E = foot(A', C, B)
draw poly A B C
draw seg D A
draw seg D B
draw seg D C
draw seg A' B dash
draw seg C A' dash
draw seg A' D' dash
draw seg C D' dash
draw seg A' E dash
draw seg E C dash
</pre><figcaption>把 $\triangle CDA$ 繞 $C$ 轉 $60^\circ$ 到 $\triangle CD'A'$；$DA+DB+DC=A'D'+D'D+DB\ge A'B$（虛線）</figcaption></figure>
<div class="cards">
<div class="card"><h4>① 轉 60°</h4><div class="rule">$\triangle CDD'$ 正三角形</div>
<div class="eg">$DC=DD'$、$DA=D'A'$ <span class="pill">換線段</span></div></div>
<div class="card"><h4>② 拉直</h4><div class="rule">最小值 $=A'B$</div>
<div class="eg">斜邊 $2$、兩股 $1,\sqrt3$：最小值 $\sqrt7$ <span class="pill">費馬點</span></div></div>
</div>
<div class="pitfall"><h4>⚠ 最常錯</h4><ul><li>三角形有一角 $\ge120^\circ$ 時，最小值點就是那個頂點，不能用這個轉法</li></ul></div>
<div class="bottomline">三段距離和 → 轉 60° 變一條折線 → 兩點之間直線最短。</div>
