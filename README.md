# 競賽數學地圖

給台灣數學教育圈的競賽數學知識平台：代數（A）、數論（N）、組合（C）、幾何（G）四大領域的單元地圖，每個單元補上思路，題目標出處、分難度，一題多解互相連結。

網站：https://vayne-poker.github.io/math-map/

## 內容

- `math-map.html`：網站本體（單元地圖、AMC 課程、依考卷、畫板）
- `amc/`：AMC 10／12 課程資料與附圖（由 `tools/build_amc_course.py` 產生）
- `data/amc_zh/`：AMC 課程的中譯與本站重寫內容，一章一檔
- `data/imo.json`、`data/apmo.json`、`data/amc_index.json`：IMO、APMO 原題索引與 AMC 場次目錄
- `tools/`：資料抽取與建置腳本

## 著作權

題目著作權屬原主辦單位，本站只做索引與引用，並標註出處。AMC 課程的章節架構與選題參考 OmegaLearn《AMC 10/12》講義（OmegaLearn.org）；定義、定理、說明與詳解由本站重寫，不轉載原書內容。
