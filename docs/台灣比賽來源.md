## 三、較有用且可免費取得的來源（初步整理）

1. **師大數學系 workshop 頁**（https://www.math.ntnu.edu.tw/workshop/110hsm/）：110 學年度決賽與北市筆試題，含解答。需確認授權後才能引用。
2. **師大科教中心《科學教育月刊》舊檔**（https://www.sec.ntnu.edu.tw/）：多篇 TRML 與競賽解析，格式清楚，但屬期刊著作。
3. **《數學傳播》**（https://www.math.sinica.edu.tw/mathmedia/journals/）：IMO 與加拿大競試解答，適合作為解答來源參考，需注意版權。
4. **九九文教基金會**（99cef.org.tw）：TRML 與 AMC 台灣承辦單位，應直接詢問授權。
5. **中華數學協會**：ARML Local 考古題，需索取，適合作為正式合作對象。

## 四、仍需詢問主辦單位的事項

- **學科能力競賽**：各年度試題與解答是否可公開再發布；是否有官方整理的歷屆題庫。
- **TMO / 選訓營**：是否公開選訓營考題；若無，能否取得授權。
- **九九文教基金會（TRML、AMC）**：歷屆試題是否可用於公開網站；AMC 試題需另向 MAA 取得授權。
- **中華數學協會（ARML Local）**：考古題能否再發布，條件為何。
- **《數學傳播》、《科學教育月刊》**：文章與解答的轉載與改寫授權。
- **各縣市教育局與學校**：國中競賽與資優甄選試題的公開條件。
